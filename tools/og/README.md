# Share image

`og.html` is the source of `assets/og.jpg`, the 1200 × 630 picture that shows when someone shares a
Draft Studio page on WhatsApp, X, Facebook, LinkedIn and others. Design pages (`d/<id>.html`) use
their own preview picture instead.

To change it: edit `og.html`, open it in a browser at exactly 1200 × 630 (or use a screenshot tool
such as Playwright), save the screenshot as `assets/og.jpg`, then publish.
